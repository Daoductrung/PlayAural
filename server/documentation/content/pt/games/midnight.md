**Midnight (1-4-24)**

Midnight, também conhecido como 1-4-24, é um jogo clássico de dados de arriscar a sorte com seis dados. Cada jogador tenta terminar um turno tendo tanto um 1 quanto um 4. Se você se qualificar, esses dois dados são reservados e os outros quatro dados se tornam sua pontuação. O melhor turno possível é 24.

**Jogabilidade**

Um jogo é disputado em um número fixo de rodadas. Em cada rodada, cada jogador ativo faz um turno completo de dados. O jogador qualificado com a maior pontuação vence a rodada.

**O Seu Turno**

1. Role todos os seis dados.

2. Após cada rolagem, mantenha pelo menos um dado recém-rolado. Você pode manter mais de um dado se isso ajudar o seu plano.

3. Os dados mantidos ficam travados quando você rola novamente. Dados travados não podem ser alterados.

4. Continue até que todos os dados estejam travados. Se todos os dados já estiverem decididos, você pode acumular o turno em vez de rolar novamente.

**Qualificação**

Para pontuar, seus dados finais devem incluir pelo menos um **1** e pelo menos um **4**. Um 1 e um 4 são removidos da pontuação. Quaisquer 1s ou 4s extras ainda contam como parte dos quatro dados de pontuação.

Se você terminar sem os dois números necessários, você não se qualifica e pontua 0 para a rodada.

**Pontuação e Vitória**

* **Pontuação do turno:** Se você se qualificar, adicione os quatro dados não obrigatórios. Pontuação máxima: 24.

* **Vitória da rodada:** O único jogador qualificado com a pontuação mais alta vence a rodada.

* **Rodada empatada:** Se vários jogadores qualificados empatarem com a pontuação mais alta, nenhuma vitória de rodada é concedida.

* **Nenhum qualificado:** Se ninguém se qualificar, nenhuma vitória de rodada é concedida.

* **Vitória do jogo:** Após o número configurado de rodadas, o jogador com mais vitórias de rodada vence o jogo. Se os jogadores ainda estiverem empatados, o jogo termina em empate.

**Verificações de Status**

* **Ler dados atuais:** Lê os dados do jogador atual, incluindo quais dados estão travados ou mantidos, o que ainda está ativo e se os dados atuais já se qualifikam.

* **Ver status da rodada:** Abre um painel de status ao vivo com o número da rodada, o turno atual, o último turno concluído e a classificação.

* **Pontuações:** Lê as vitórias de rodada de cada jogador. Pontuações detalhadas abrem um painel de classificação ao vivo.

**Exemplo de Turno**

1. Você rola: **3-1-5-4-2-6**.

2. Você mantém o 1 e o 4 para se qualificar, e também mantém o 6.

3. Você rola os três dados restantes: **2-5-3**. Você mantém o 5.

4. Você rola os dois últimos dados: **6-6**. O turno está completo.

5. Seus dados finais são 1, 4, 6, 5, 6 e 6. O 1 e o 4 qualificam você; a pontuação é 6 + 5 + 6 + 6 = 23.

**Opções de Jogo**

* **Rodadas:** Número de rodadas a jogar (padrão 5, intervalo de 1 a 20).

**Opções Pessoais**

* **Estilo de manutenção de dados:** Com Índices de dados, pressione 1-6 para alternar os dados por posição. Com Valores de dados, cada dado recém-rolado começa mantido; pressione 1-6 para liberar um dado correspondente para a próxima rolagem, ou Shift+1-6 para manter um dado correspondente liberado novamente. Repita uma tecla para lidar com valores duplicados um dado de cada vez.

**Atalhos de Teclado**

* **R:** Rolar os dados.

* **1-6:** Alternar por posição no modo de índices de dados, ou liberar um dado mantido correspondente no modo de valores de dados.

* **Shift+1-6:** No modo de valores de dados, manter um dado liberado correspondente.

* **B:** Acumular sua pontuação assim que cada dado estiver decidido.

* **H:** Ler os dados atuais.

* **E:** Ver o status da rodada.

* **S:** Ler pontuações.

* **Shift+S:** Ver pontuações detalhadas.
