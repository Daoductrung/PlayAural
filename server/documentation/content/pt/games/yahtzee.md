**Yahtzee**

Yahtzee é um jogo de dados clássico sobre fazer o melhor uso de cinco dados. A cada turno, você pode rolar até três vezes, guardar os dados que gostar e, em seguida, escrever uma pontuação em sua cartela. Cada categoria de pontuação pode ser usada apenas uma vez.

O jogador com a pontuação total mais alta após cada jogador preencher todas as 13 categorias vence.

**Como Jogar**

Yahtzee suporta de 1 a 4 jogadores. Jogos solo estão disponíveis para prática e não contam para placares competitivos ou estatísticas multiplayer.

1. **Rolar:** Pressione Rolar dados para rolar todos os cinco dados.

2. **Guardar dados:** Após uma rolagem, guarde quaisquer dados que desejar salvar. Os dados guardados permanecem como estão quando você rola novamente.

3. **Rolar novamente:** Você pode rolar até mais duas vezes. Apenas os dados que não foram guardados são rolados novamente.

4. **Pontuar:** Escolha uma categoria aberta em sua cartela. Se os dados não corresponderem a essa categoria, você pontua 0 nela.

Você deve pontuar uma vez a cada turno. Não há passe.

**Seção Superior**

A seção superior pontua apenas dados que mostram o número correspondente.

* **1s:** Total de todos os 1s.
* **2s:** Total de todos os 2s.
* **3s:** Total de todos os 3s.
* **4s:** Total de todos os 4s.
* **5s:** Total de todos os 5s.
* **6s:** Total de todos os 6s.

Se o total da sua seção superior atingir 63 ou mais, você recebe um bônus de 35 pontos.

**Seção Inferior**

* **Trinca:** Pelo menos três dados mostram o mesmo número. Pontua o total de todos os cinco dados.
* **Quadra:** Pelo menos quatro dados mostram o mesmo número. Pontua o total de todos os cinco dados.
* **Full House:** Três dados mostram um número e dois dados mostram outro número. Pontua 25.
* **Sequência menor:** Quatro números em sequência: 1-2-3-4, 2-3-4-5 ou 3-4-5-6. Pontua 30.
* **Sequência maior:** Cinco números em sequência: 1-2-3-4-5 ou 2-3-4-5-6. Pontua 40.
* **Yahtzee:** Todos os cinco dados mostram o mesmo número. Pontua 50.
* **Chance:** Quaisquer dados. Pontua o total de todos os cinco dados.

**Bônus Yahtzee e Regra do curinga**

Se você já pontuou 50 em Yahtzee e rolar outro Yahtzee, você recebe um bônus de 100 pontos.

Após qualquer Yahtzee posterior, quando a caixa Yahtzee já estiver preenchida, a regra do curinga decide onde você pode pontuar:

* Se a caixa da seção superior correspondente ainda estiver aberta, você deve pontuar lá primeiro. Por exemplo, cinco 6s devem ir em 6s.
* Se essa caixa superior correspondente já estiver preenchida, escolha qualquer categoria aberta da seção inferior. Full House, Sequência menor e Sequência maior pontuam seus valores fixos sob a regra do curinga.
* Se a caixa superior correspondente e todas as categorias da seção inferior estiverem preenchidas, escolha qualquer categoria aberta da seção superior e pontue 0 nela.

**Cartelas de Pontuação**

* **Verificar cartela:** Abre sua própria cartela de pontuação.
* **Verificar a cartela de todos os jogadores:** Abre uma lista de jogadores e, em seguida, mostra a cartela de pontuação do jogador selecionado. Espectadores também podem usar esta ação.

**Opções do Jogo**

* **Número de partidas:** Quantas partidas completas de 13 turnos jogar em uma sessão. O padrão é 1.

**Opções Pessoais**

* **Anúncios breves:** Encurta as mensagens de rolagem, pontuação e bônus.
* **Estilo de retenção de dados:** Com Índices de dados, pressione 1-5 para alternar os dados por posição. Com Valores de dados, pressione 1-6 para liberar um dado guardado com esse valor, ou Shift+1-6 para guardar um dado liberado com esse valor.
* **Limpar dados guardados ao rolar:** Quando ativado, os dados são liberados após cada rolagem, para que você escolha o que guardar novamente a partir do novo resultado.

**Atalhos de Teclado**

* **R:** Rolar dados.
* **1-5:** No modo de índices de dados, alterna os dados por posição.
* **1-6:** No modo de valores de dados, libera um dado guardado que mostra esse valor.
* **Shift+1-6:** No modo de valores de dados, guarda um dado liberado que mostra esse valor.
* **D:** Verificar dados.
* **C:** Verificar cartela.
* **Shift+C:** Verificar a cartela de todos os jogadores.
